A browser extension for raw-manga readers. Switch it on for a tab, and every speech bubble gets covered by a natural, meaning-first translation in hand-lettered comic text.

Now we know
The reader switches it on per tab from the popup or right-click. It stays on across chapters, shows loading indicators on each bubble, chimes once on the first page, and shows one toast per chapter after that.

→
Now we know
Toggle, language, opacity, and chime/toast preferences. Changing the language retranslates only the current chapter, and turning it off keeps finished translations.

    Features and behavior

    Each area lists the checks we'll use during the build to confirm it works.

    Switching on for a tab4 checks

    Why: always-on wastes AI credits and gets in the way

    • Installed but off → the chapter looks unchanged
    • Popup toggle on → pages on that tab start translating
    • Right-click “Translate this page” → same effect
    • Popup shows “on” whichever route was used
    Staying on across chapters2 checks
    • Next chapter in the same tab translates with no action
    • Other tabs are unaffected
    Bubble translation and overlay4 checks

    Develops scope › The Unique Kernel

    • Each bubble gets its own translation, placed over it
    • Reads naturally, by meaning: “How did you get the other way?” → “How did you get into my house?”
    • Fully covers the original at 0.95 by default, in a hand-lettered font, fitted to the bubble
    • Translates on scroll-in, and may pre-translate pages just ahead
    Loading feedback5 checks
    • Loading indicator on each bubble while translating
    • Indicators are replaced by the translation
    • First page: chime + toast
    • After that: one toast per chapter, never per page
    • Chime and toasts can each be turned off
    Settings3 checks
    • Language: phase one English only, then Spanish and French for the demo
    • Opacity slider (default 0.95) updates translated bubbles live
    • Chime on/off and toasts on/off
    Changing language mid-chapter3 checks
    • Current chapter is retranslated into the new language
    • Earlier chapters keep their language
    • Later chapters use the new language
    Turning off2 checks
    • No new pages are translated
    • Already-translated pages keep their translations
    When translation fails3 checks
    • Failed page → raw bubbles + error toast + retry
    • Retry → translates like any page on success
    • One unreadable bubble stays raw, and the rest of the page still translates

    Look and feel

    Magenta
    Accent range
    Mid-tone purple
    Dark, Crunchyroll-inspired

    Rule: never color only one side of a border. Borders are uniform all the way around or absent, toasts included.

    Bubble lettering is hand-lettered comic, not a plain font. Example:

    How did you get into my house?!

    States

    StateWhat the reader sees
    Off (default)The site, exactly as normal
    TranslatingLoading indicators on the bubbles of pages in view
    TranslatedTranslated bubbles, plus chime + toast on the first page and one toast per chapter after
    Failed pageRaw bubbles, error toast, retry
    No bubbles (assumption)Left alone, with no error
    Switched offExisting translations stay, and new pages stay raw
    Remembered (assumption)Language, opacity, chime, and toast preferences between sessions

    Boundary

    Deferred from the PoC3
    • Waiting-room mini-game / jokes / comedic panels: a separate project that doesn't prove translation works
    • Many manga sites: one or two first
    • Translation caching
    Later enhancements4
    • Curved text and matching each bubble's lettering
    • Sound effects and text outside bubbles
    • Korean, Chinese, and more target languages
    • Fully polished settings
    Non-goals3
    • Whole-story memory across chapters
    • Always-on translation
    • Standalone reader site

    Open questions

    • Where the retry option sits on a failed page (a button on the page, or in the toast?). Doesn't block approval and can be settled in spec/build.
