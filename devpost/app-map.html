InkSwap app map

A Chrome extension that translates raw manga where you read it, bubble by bubble, by meaning. This map shows where things live, so you know where a change belongs.

The main pieces

  • PopupThe on/off switch for the tab, language, bubble opacity, chime and toasts, saved translations, and your Claude key. entrypoints/popup/
  • Page helperRuns on MangaDex and Shonen Jump+. Finds the manga pages, captures each one, and draws the translations over it. entrypoints/content/index.ts
  • Background workerRemembers which tabs are on, finds the bubbles, checks saved translations, and calls Claude (at most 2 at once per tab). entrypoints/background.ts
  • Claude + your promptOne call per page: reads the page and returns each bubble's translation. lib/translate.ts, lib/prompt.ts

One action, end to end: a page comes into view

A route through the code (reference)

Three stops that follow the action above. Open them in your editor and search for the anchor. Line numbers drift; anchors don't.

  1. The page comes into view and is captured

    entrypoints/content/index.ts → search async function handlePage; capture in lib/capture.ts → export async function capturePage

    This is where InkSwap notices a page, shows the spinner, takes the page's picture (read directly on MangaDex, a screenshot crop on Shonen Jump+), and sends it to the background worker. When the answer comes back, it shows the toast or the Retry pill.
  2. The background worker decides: saved, or ask Claude?

    entrypoints/background.ts → search async function translate( and cache.lookup(fp, language); bubbles in lib/bubbles.ts → export function findBubbles

    It finds the bubbles (closed white shapes with letters as holes), fingerprints the page, and returns a saved translation if there is one. Otherwise it sends Claude the page plus a numbered copy, then gives each line its bubble's exact shape and saves the result.
  3. Claude translates with your prompt; the overlay draws it

    lib/translate.ts → export async function translatePage; lib/prompt.ts → export const prompt; drawing in lib/overlay.ts → async setBubbles

    The request is your prompt plus a short note the code writes about the two images and the target language. The JSON answer is checked, then each bubble is painted in its shape and its text shrunk until it fits.

A practice to reuse

Test a prompt's assumptions with an input that breaks them. The translation prompt says the source text is "currently Japanese". That was true when it was written. In the final review a Spanish chapter came out with pages left blank. The cause wasn't a code bug: told the source was Japanese, Claude sometimes returned nothing for Spanish pages. On one page, the same request failed 3 out of 3 times; adding one sentence saying the page can be in any language translated every line, 3 out of 3.

Where it lives: lib/prompt.ts (the assumption), lib/translate.ts → can be in any language (the fix), scripts/check-longstrip.mjs (the check that now guards it).

On another project: when a prompt states something about its input (language, format, length, who's asking), try one real input that doesn't fit before trusting it, and compare a few runs of each version, since a single run can mislead.
