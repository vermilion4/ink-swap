InkSwap Blueprint

How InkSwap is built: four pieces, one Claude call per page, no server of our own.

Chrome extension (MV3) TypeScript + WXT Claude Sonnet 5.5 Bring-your-own API key ~1¢/page (estimate)

How this works, in plain language

  1. Popup: the panel behind the InkSwap icon. It has the on/off toggle, language, opacity, chime and toasts switches, and your API key.
  2. Background worker: the brain. It remembers which tabs are on, adds the right-click item, and is the only piece that talks to Claude.
  3. Page helper: code placed inside the manga site's page. It finds page images, notices them scrolling in, and draws spinners, translated bubbles, toasts, and Retry.
  4. Claude Sonnet 5.5: gets one page image and returns "here's every bubble's box, and its meaning-first translation."

Why one Claude call instead of separate text-recognition and translation services: Claude sees the whole page (speaker, scene, art), which is what makes "I live in Lagos" possible. It's also one service, one key, and one failure point.

InkSwap doesn't know where the bubbles are until Claude answers, so the proof of concept uses A. You'll try B as a stretch once the demo works.

A · Page spinner (building now)

One spinner over the whole page until the translations land. Simple and low-risk.

B · Per-bubble (post-demo stretch)

Stream Claude's answer with all bubble boxes first, so spinners appear on each bubble within seconds and translations fill in after. More code and more risk in a 2–4 hour build.

What Claude returns (enforced by zod):

{ bubbles: [{
    box: { x, y, w, h },     // 0–1000, relative to the page image
    source: "どうやって家に入った？",
    translation: "How did you get into my house?",
    readable: true           // false → leave the bubble raw
}] }

Look and feel

Magenta → purple accent. The theme follows the system: Crunchyroll-style dark, or a soft light version.

How did you get into my house?!

Bubble text uses Shantell Sans (hand-lettered, with Spanish and French accents), and the wordmark uses Bangers. Both are free to bundle. Borders are uniform or absent, never one-sided.

Run it & demo it

  • Develop: npm install → npm run dev (WXT opens Chrome with InkSwap loaded)
  • Try it like a stranger: npm run build → chrome://extensions → Developer mode → Load unpacked → .output/chrome-mv3
  • Demo video: right-click → Translate, the spinner, the page landing with the chime and toast, the next page, then a switch to Spanish. Show only a few pages.
  • No deployment. The public repo plus the video are the submission.
